# Honey Bees

موقع عربي لبيع النحل والعسل ومستلزمات المناحل.

## التشغيل محلياً

افتح `index.html` في المتصفح، أو شغّل خادماً بسيطاً:

```bash
python3 -m http.server 8080
```

ثم افتح [http://localhost:8080](http://localhost:8080).

## قبل النشر

استبدل رقم واتساب التجريبي `96500000000` برقمك الحقيقي في `index.html`.

## النشر على Hostinger

ارفع ملفات المشروع إلى مجلد الموقع العام (عادة `public_html`).
