# الرباعية للنحل والعسل | Al Rabaa Apiaries

موقع تعريفي وطلبيات عبر واتساب لمنتجات النحل والعسل ومستلزمات المناحل.

**الشعار:** من الطبيعة .. لجودة تدوم

## التشغيل محلياً

```bash
python3 -m http.server 8080
```

افتح [http://localhost:8080](http://localhost:8080).

## سجل العملاء والفاتورة الإلكترونية

لوحة الإدارة: [admin.html](https://raspybd.github.io/honey-bees/admin.html)

- إضافة وتعديل العملاء
- إصدار فاتورة إلكترونية مع بنود وأسعار
- طباعة / حفظ PDF ومشاركة عبر واتساب
- تصدير واستيراد نسخة احتياطية JSON

البيانات تُحفظ محليًا في متصفح الجهاز (localStorage). صدّر نسخة احتياطية بانتظام.
