# الرباعية للنحل والعسل | Al Rabaa Apiaries

موقع تعريفي وطلبيات عبر واتساب لمنتجات النحل والعسل ومستلزمات المناحل.

**الشعار:** من الطبيعة .. لجودة تدوم

## التشغيل محلياً

```bash
python3 -m http.server 8080
```

افتح [http://localhost:8080](http://localhost:8080).

## قبل الإطلاق

استبدل رقم واتساب التجريبي `96599787742` في `index.html` برقمك الحقيقي.

## النشر

الموقع منشور عبر GitHub Pages من فرع `main`.
